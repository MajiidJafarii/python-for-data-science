<h1 dir="rtl">پایتون مقدماتی برای علوم داده</h1>

<p dir="rtl">
مجموعه‌ی نوت‌بوک‌هایی برای مرور پایتون و شروع تحلیل داده؛
از مفاهیم پایه تا NumPy، Pandas و Matplotlib.
</p>

<h2 dir="rtl">محتوای دوره</h2>

<ul dir="rtl">
  <li>مبانی پایتون، تابع، کلاس، فایل و مدیریت خطا</li>
  <li>نصب پایتون، pip و محیط مجازی venv</li>
  <li>NumPy، جبر خطی، احتمال و آمار</li>
  <li>Pandas، پاک‌سازی داده، Iris و سری زمانی</li>
  <li>مصورسازی داده با Matplotlib</li>
</ul>

<h2 dir="rtl">اجرا</h2>

```bash
git clone https://github.com/MajiidJafarii/python-for-data-science.git
cd python-for-data-science

python3 -m venv .venv
source .venv/bin/activate

python -m pip install numpy pandas matplotlib scikit-learn jupyterlab
python -m jupyter lab
```

<p dir="rtl">
نوت‌بوک‌ها داخل پوشهٔ <code>notebooks</code> قرار دارند و شامل توضیح، مثال و تمرین هستند.
</p>
